# SDK Migration Guide: 0.2.x to 0.3.x

## Overview

This guide describes breaking changes and migration steps when upgrading `@stellarforge-protocol/sdk` from `0.2.x` to `0.3.x`.

## Key Changes

### 1. Mandatory RPC URL in Custom Configuration
In version 0.3.0, SDF no longer provides a default mainnet Soroban RPC endpoint. `MAINNET_CONFIG` now omits `rpcUrl`, requiring applications to explicitly supply an RPC provider endpoint (e.g. from an RPC node provider).

```ts
// Before (0.2.x):
import { MAINNET_CONFIG } from "@stellarforge-protocol/sdk";
const client = new RwaAssetClient(MAINNET_CONFIG);

// After (0.3.x):
import { MAINNET_CONFIG } from "@stellarforge-protocol/sdk";
const client = new RwaAssetClient({
  ...MAINNET_CONFIG,
  rpcUrl: "https://your-mainnet-rpc-node.com",
  contracts: { /* ... */ }
});
```

### 2. Event Pagination Helper
The `getEventsPaginated` utility has been introduced to safely fetch event ranges exceeding single-page RPC limits without manual cursor handling.

### 3. Explicit Admin Handover
Two-step admin transfer (`proposeAdmin` and `acceptAdmin`) replaces single-step transfers, requiring authorization from both the current admin and the incoming admin.
