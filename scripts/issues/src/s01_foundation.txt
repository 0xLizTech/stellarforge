#STAGE Stage 1: Repository, Tooling and Developer Experience
#PHASE phase-1
#CONTEXT StellarForge is a Soroban workspace (`contracts/*`) plus a TypeScript SDK (`sdk/`). Phase 1 is feature complete, so this stage removes friction for new contributors and makes the toolchain trustworthy before more contracts land.
#OOS Changes to contract behavior or SDK public APIs unless the issue says so.
